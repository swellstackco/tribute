# Tribute

A celebration of life that sounds and tastes like them. AI memorial tools guess. Tribute knows.

Tell Tribute five to ten things someone loved. It builds the music, readings, food, a place to gather,
slideshow eras and a printed program. Every pick comes from Qloo's taste graph, with the evidence on the card.

Tribute is a planning aid. It is not grief counseling.

## Run it (no keys needed)

    npm install
    npm run seed:examples
    npm run dev        # server on :5117, web on http://localhost:5173
